# Contributing during bootstrap

The owner is validating the first local core. Keep changes small, read `AGENTS.md`, and check scope before opening large feature work. The final open-source license and contribution policy are not selected yet.

After installing dependencies with pnpm, run `pnpm check` and `pnpm demo`. Add a regression test for a bug fix. Do not weaken exact-text/version checks, turn heuristic hints into factual verdicts, or add network-dependent tests to the default suite.

Use feature branches and PRs. Describe user-visible behavior, risks, tests actually run, and tests not run. Never include private manuscripts, credentials, local SQLite files or generated build outputs. Once generated by pnpm, the lockfile belongs in version control.
