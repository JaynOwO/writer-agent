# Changelog

## 0.0.2 — model-provider development preview

Adopt Apache-2.0 (LICENSE, NOTICE, all package metadata and contribution docs). Add Proposal Protocol v1 with strict response/application validation; native Ollama and OpenAI Chat Completions-compatible adapters; bounded, cancellable HTTP with safe errors, redirect refusal and explicit remote permission. Add preview-first CLI suggest, environment-name credential configuration, deterministic HTTP tests and a synthetic provider demo.

Keep database schema v1, original text/version/transaction invariants and pinned dependency lockfile. Add no third-party dependencies. No GUI, real-provider quality claim, streaming, source/claim graph, memory learning or MCP/Skills execution.

## 0.0.1 — development preview

Added local SQLite workspaces, immutable revision snapshots, block-level proposed changes, explicit accept/reject/revert operations, decision reasons, and conflict/ABA protection. Added the scripted model adapter, four deliberately limited lexical review checks, a CLI and an offline demonstration. Added automated core/storage/model/CLI tests and CI configuration.

Not a release of a full writing assistant. No real models, research, claim/evidence graph, intent analysis, long-term preference learning, graphical UI, MCP or Skills execution. License selection and integrator validation remain outstanding.
