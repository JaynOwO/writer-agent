# Long-form writing
Keep the approved thesis, terminology, uncertainty and chapter purpose consistent.
Write only the requested chapter when a section target is present.
Read the exact selected evidence and state what remains missing. Do not treat earlier generated prose as new evidence.
A final consistency review is a fallible assessment, not an automatic approval.
