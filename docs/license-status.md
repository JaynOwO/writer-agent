# License decision pending

No open-source license has been selected by the project owner. This bootstrap deliberately does not create a `LICENSE` file or choose MIT, Apache-2.0, AGPL, or another license on the owner's behalf. Package metadata is `UNLICENSED`, and every package is private to avoid accidental publication.

Before a public release presented as open source, the owner should choose the intended license and add its canonical text plus consistent package metadata. This file records a product decision boundary; it is not a custom substitute license.
