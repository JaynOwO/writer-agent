# Siglum v0.0.6 implementation & acceptance specification

Owner decisions: 1B/2C/3B/4B/5C/6B. Based on main `7b7d252165b3723bd5f22e3e56907f722e1c148c` (v0.0.5).

## Implemented scope

Phase grants, bounded foreground execution of three fixed templates, native Tavily basic Search, public-only query planning, source discovery/capture/selected context, outline and candidate artifacts, one optional revision, explicit adoption, durable attempts/quotas, lease fencing, explicit unknown-outcome recovery and bilingual numbered menus.

The full approved planning text is summarized by the protocol and paired guides rather than treated as a report of real inference. `docs/workflow-protocol.md` defines exact current wire/bounds/state behavior; `docs/workflows.md` and `docs/workflows.zh-CN.md` give runnable CLI/guide instructions. No library, repository, .writer path, package scope, license or updater-format renames.

## Acceptance gates

1. Create/preview perform no network; only an exact stage grant allows execution. Grants cannot be minted by model output.
2. Public query input excludes manuscripts, source notes and memory examples. Search snippets stay discoveries; only actually saved page/excerpt content feeds outlines/drafts.
3. Each template stops at its defined author decision gate. New drafts never become documents without adoption; old alternatives retain official baseline and independent-block preconditions.
4. All task output has strict shape/identity/quote validation. Parent artifacts remain explicit, not fabricated document revisions. No findings is not a quality certificate.
5. Attempts/quotas persist before sends. Reserved/dispatched/completed/failed/outcome-unknown are distinguishable, and explicit retry keeps prior quota costs. Duplicate author adoption does not create duplicate documents.
6. Short transactions/SAVEPOINTs commit source/proposal/report effects atomically with checkpoints. Two concurrent workers cannot share a run generation; late results from an expired/revoked lease cannot commit.
7. Relevant changed input requires recapture/consent and invalidates private descendants, preserving source/history caches. Budget-only changes revoke grants without erasing matching results. One successful automatic revision total per run.
8. Schema v5 is additive; backups preserve all prior v1–v4 rows. Installation never opens private workspaces. Unknown schemas fail closed; SQLite connections close before directory cleanup.
9. Numbered guide handles cancel/EOF/non-TTY and never treats absent input as Yes. Default tests include the synthetic workflow demonstration and all prior regression tests.
10. Bilingual README/guide facts and executable examples agree; source hash manifest and importer work with installed Updater v0.1.2. No direct GitHub writes, paid requests or private workspace migrations during development.

## Explicit first-version limits

New-article supports real web research or selected local materials. Existing-article revise/review templates use explicitly saved sources only. Source selection prioritizes one host then result order, not credibility assessment. Automatically fetched page context is a disclosed prefix (40 complete lines/8000 bytes), not full semantic extraction. Discussion replies regenerate an outline within the same spent budget after explicit renewal, not unlimited autonomous conversation.

New-article run-owned intent can be supplied in config; the guide collects goal/language/profile as its concise path. Existing document intent/memory remains attached through existing services. Candidate B is not reviewed by an extra hidden call. Comparison is exact strings plus prefix/suffix spans; no sentence-level independent adoption or safe substring rollback. Scalar monetary costs remain unknown absent verified billing data.

No GUI, daemon, general YAML/code workflows, streaming, browser automation/login, PDF, Skills/MCP, passive memory activation or new third-party dependencies. Protocol-schema correctness/loopback tests are not real-model writing-quality validation.
