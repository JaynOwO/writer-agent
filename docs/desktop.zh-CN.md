# Siglum v0.0.9 桌面开发预览

## 这个版本是什么

本地 Electron 桌面写作程序，不是远程网站，也不是生成的 HTML 报告。SQLite 仍为正式文稿存储；界面只通过受限 preload 调用业务，数据库、凭据和工作流在独立 utility process 中运行。界面没有 Git、任意命令、SQL 或任意路径文件接口。

Windows x64 发行物是**便携文件夹＋需要明确确认的内置当前用户安装操作**，不是单独签名的 Setup.exe/MSI。完整解压，保留 DESKTOP_MANIFEST.json，与 Siglum.exe 一起使用。打开程序不授权网络请求。「安装到本机」将验证后的文件复制到 LocalApplicationData/Programs/Siglum 下的版本目录，添加桌面／开始菜单快捷方式及当前用户卸载条目；旧版本与私人数据保留。卸载检查文件归属，不删除文稿、连接或 OS 密钥。注册表／快捷方式／安装流程需要在 Windows 实测，不能用 Linux 文件复制测试冒充。应用代码没有 Authenticode 签名，不要关闭 Smart App Control／SmartScreen。

普通写作者使用桌面文件夹无需 Git 或另装 Node；从源码开发仍需要已说明的 Node/pnpm。源码集成 Updater 是另一应用和权限边界。

## 第一次写作

通过原生对话框打开或创建写作工作区。v1–v6 旧工作区在范围编辑前需要另行明确备份升级到 schema7，请先关闭其他会话。安装／更新代码不会迁移私稿数据库。

导入 UTF-8 Markdown／文本或创建文章。编辑保留稳定块 ID；输入法组合结束后自动保存独立编辑缓冲，「保存正文」才提交正式版本。缓冲保存不等于批准模型提案。旧缓冲遇到并发修改时保留，不强行覆盖；明确丢弃前请复制需要的文字。断电时最后尚未落盘字符不能保证恢复。跨块拆分／合并／移动不是首版编辑操作。

创建／选择模型连接，仍支持 Ollama 和 Chat Completions 兼容接口，不附送模型或 API 额度。OS 库／环境变量／本次会话／无凭据模式明确选择，密钥不返回界面。高级 Skill／MCP 配置、偏好归纳／导入和部分细致来源／片段管理仍使用既有 CLI 向导。桌面可继续已有扩展工作流；桌面新任务目前选择已存资料或内置搜索，不在此页配置任意新的工具授权。

## 逐范围审核

请求修改、选择资料后，先确认准确预览再派发。模型输出仍是待审核块提案。「拆分为可审核范围」创建宿主派生、固定该提案与基线的独立范围集合，不改写原历史。只勾选需要的范围；采用／拒绝／撤回均为明确决定，选中集合原子提交。

真正的操作单位是稳定块内的替换／插入／删除，不是模型自称的句子编号或全文第一次匹配。不相交历史可以确定性映射；同位置插入歧义、切开字素、依赖不完整、重叠和历史缺失会拒绝修改。补偿撤回保留不相关已采用内容；后来人工编辑重叠区域时阻止直接撤回，不恢复整个旧段落。历史整块已接受修改仍有原来的明确撤回入口。

范围语义审稿按当前映射文字组合选中待决操作；精确引文／坐标校验、机械观察和模型判断分别展示。即使拒绝操作没有改变正文版本，也能使相关报告过期。引用固定来源条目与文本版本，不认证支持关系，后续修改保守标为需要核查。

## 写作任务与连接

保留新稿、改旧稿、只审核待采用块提案三个模板；范围审稿在文章侧栏。新稿的导航摘要和逐章起草需要主动开启，旧稿模板使用当前意图与档案。阶段预览固定模型、来源、预算及输入；大纲另行确认后才授权写作。采用候选幂等；预览／自动保存不批准 AI 正文。

任务页显示已存产物、暂停／未知结果与明确的重试／恢复。关闭窗口前，有未落盘输入或任务时询问；已保存成果保留，已派发请求可能结果未知。没有秘密常驻服务或自动重试。回环模型服务本身也可能转发到云端。

HTML 阅读报告仍为转义、只读的时间点导出，不增加写操作按钮。只导出选定内容组；正文可能已引用私人文字，排除元数据并不等于语义脱敏。文稿库／备份／报告均为未加密私人数据。

## 源码开发

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm desktop:runtime
pnpm desktop
```

`desktop:runtime` 明确下载 apps/desktop/runtime-lock.json 固定的官方运行时并校验大小／SHA-256，不安装包、启动下载程序或访问凭据。`desktop` 不隐式下载，可以通过 `--runtime` 指定已信任的运行时目录。运行时独立于真实 pnpm 锁文件固定，不虚构安装过 npm Electron 包。

```sh
pnpm desktop:smoke
pnpm test:interfaces
```

桌面烟雾测试创建临时虚构工作区与本机模型服务，不是真实推理。Linux 需要图形显示或 xvfb，且使用支持沙箱的普通用户，不添加 --no-sandbox。Windows 直接运行桌面。源码测试、实际窗口、Windows 安装、系统凭据会话、GitHub CI 与真实服务质量分别记录。
