# Known limitations — Siglum v0.0.3

Use disposable/test manuscripts and separate backups. This is a CLI development preview, not a production writing IDE.

1. **No autonomous researcher or web-wide search.** The source layer captures an explicitly selected public URL or local file. `source search` searches saved material using a case-sensitive Unicode substring; it does not query a search engine. No crawling, browser automation, paywall/login bypass, or automatic source selection.
2. **No GUI, full Semantic Diff, Claim Ledger or writing memory.** There is no argument/evidence entailment verdict, intent contract, preference learning, embeddings, streaming, MCP or Skills execution. The four existing lexical warnings and model notes are not fact checks.
3. **Block-level edits only.** Blank-line segmentation is lossless text segmentation, not a Markdown AST. One block per change; no sentence-level selection, structural moves, automatic rebase or dependency-aware revert. Same-block edits invalidate old proposals/reverts even when the text returns to an earlier value.
4. **Source context is not evidence support.** Provenance records which exact snapshots/excerpts were supplied with a successful proposal. It does not prove that the model read or used them, that they are true, or that any particular edit is supported. Manual paragraph links are likewise unverified. A changed block makes its old link stale; links are not automatically repaired.
5. **Small static-text capture, not a full browser/parser.** Only UTF-8 HTML, plain text and Markdown are accepted. No PDF/DOCX, OCR, JavaScript-rendered pages, full HTML5 parsing, CSS visibility evaluation, table reconstruction, embedded assets or complete named-entity decoding. HTML navigation and malformed markup may affect extraction. Inspect retained raw bytes and original material for important quotations.
6. **Conservative retrieval compatibility.** Public HTTP(S) on default ports only; redirects, credentials in URLs, compressed responses and non-UTF-8 charsets are refused. No retries. A legitimate site may fail these constraints. There is a total deadline and byte cap; no arbitrary private-network opt-out in the CLI. DNS/address checks and pinning are defense in depth, not a replacement for operating-system/network egress controls.
7. **Bounded prototype, not a large research archive.** Each raw capture is at most 2,000,000 bytes and extracted text at most 1,000,000 UTF-8 bytes. Context is at most eight selected snapshots/excerpts and 80,000 serialized UTF-8 bytes. Source list/search have finite result limits; snapshot/note history has no pagination. Whole snapshots and proposal-context text are duplicated. No compaction or automated retention.
8. **Reported metadata can be wrong.** Missing title/author/publisher/publication time remains null, not guessed. Available HTML metadata is an unverified publisher declaration. `capturedAt` is the local capture time, not the publication date. Hashes detect accidental mismatch with stored bytes; they do not establish authenticity or resist an attacker who controls the database and hashes.
9. **One storage authority and explicit migration.** SQLite is canonical; Markdown imports create new documents and exports refuse existing paths. No live file sync. New workspaces use schema v2. Old schema-v1 manuscript operations remain supported, but source features require explicit `migrate --apply`, which creates and verifies a schema-v1 backup before an additive transaction. Close old application versions first. A code update never silently migrates user data. Migration backup is not a general backup schedule.
10. **Local data is not encrypted.** Sources, private notes, instructions and manuscript history stay in the selected workspace unless explicitly exported or sent. `--send` sends the selected manuscript and chosen source context to the configured model; remote endpoints require `--allow-remote`. A loopback model server can itself forward to a cloud provider. No notes or other library sources are automatically attached.
11. **Limited inference/audit compatibility.** Native Ollama and OpenAI Chat Completions-compatible non-streaming formats are implemented, not every service/model or Responses API. No model download, discovery, repair, fallback, retry, exact dollar budget or OS secret vault. Source-backed successful proposals record context, but not complete network traces, billing or transient model notes. A failed or cancelled response saves no proposal context. Cancellation cannot guarantee the upstream provider stopped billing.
12. **Platform and model tests are separate.** CI is configured for Linux/Windows with Node 22/24; consult this delivery's validation report and actual CI rather than inferring success from the previous release. `node:sqlite` is experimental on Node 22. Default tests/demos use synthetic fixtures and loopback services, not live web research or real AI-quality evaluation.
13. **Documentation parity is mechanical.** README checks compare version/license, marked sections/features/limitations, command examples and existing local links. They cannot prove translation accuracy, validate every prose claim or check all link anchors. Supporting technical documentation is not yet fully bilingual.
14. **Rights remain separate.** Apache-2.0 covers project code, not a blanket license for imported websites, manuscripts, model weights or provider services. No domain or trademark clearance is asserted for the Siglum name.
