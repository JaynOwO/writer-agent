1. Shared user-local product services, bilingual numbered operations, local metadata diagnostics and separately authorized model/search/MCP/keyring probes.
2. Actually installed pinned official MCP SDK2.0.0 replaces native protocol execution. Host bounding/identity/schema policy remains. 3. Optional derived navigation summaries over selected original evidence. They are versioned, quoted, limited, cached via existing workflow attempts and consume model budgets. 4. Static bilingual HTML snapshots with opt-in private content groups, full-text comparisons, source/author guidance and generation-time recovery state. No script, remote assets, hidden excluded fields, HTTP backend or executable approval controls. No overwrite or false live status.
5. Named model/search/MCP settings plus keyring2.1.0 OS credential references; Linux explicitly Secret Service. Masked terminal input, isolated recoverable self-tests, append-only preset versions, exact-target local task bindings and nonsecret journals. No implicit fallback, all-key enumeration or real provider key revocation.

Workspace schema remains6. New optional config/request fields have exact validation and legacy absence retains previous behavior. User-level metadata schema1 is separate; OS secrets are not workspace data. A new connection version invalidates dependent local bindings/ongoing results, not unrelated tasks. No network or OS-key await holds a database transaction. Existing permissions, leases, attempt quota and human manuscript decisions remain authoritative.

The SDK dependency gate was fulfilled using integrity-verified public archives supplied by the owner and a real pnpm installation against an isolated offline mirror. The generated lockfile includes registry integrities, no local build URLs. No fictional SDK declarations, native protocol substitution or fabricated dependency lock is included.

Implemented refinements versus the original plan: navigation keeps the full selected original packet (not lossy evidence compression); first-party SDK fixtures are not independent server proof; stdio secrets retain explicit environment-name configuration; OS preset authentication is for model/search/HTTP MCP. Source and guidance report switches exclude their own structured groups, not semantic repetitions already present in approved text. File-system hardlink support is needed for no-overwrite report publication. No GUI, OAuth, background runtime, word/sentence rollback or auto paid requests are added.

Required checks: typecheck/build/regressions, old and new demos, SDK wire/server fixtures, credential-target/compensation/fake-store tests, summary/citation/original provenance, browser rendering and exclusion, terminal masked input/cancellation, truthful per-OS/dependency/service reports, bilingual parity and format-1 delivery checks.
